## Feature Status Definitions

| Status      | Meaning                                  |
| ----------- | ---------------------------------------- |
| NOT_STARTED | No implementation work                   |
| READY       | Approved and dependencies satisfied      |
| IN_PROGRESS | Implementation underway                  |
| BLOCKED     | Dependency or decision prevents progress |
| IMPLEMENTED | Code exists, verification incomplete     |
| VERIFIED    | Required automated verification passes   |
| DONE        | Verified and accepted                    |

## Updating Feature Status

For every status change, record:

- Feature ID
- Previous status
- New status
- Related task ID
- Evidence: code paths, tests, and commit
- Verification result
- Date

A feature may be marked DONE only when its
documented acceptance criteria are satisfied.
